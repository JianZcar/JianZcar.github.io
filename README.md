# Jian Z'car Portfolio

Personal portfolio and technical blog built with Nuxt.js, Tailwind CSS, and Nuxt Content.

## Features

- **System Telemetry Interface:** A custom-built terminal emulator showcasing project build pipelines.
- **Cyberpunk Aesthetic:** Minimalist, high-performance design with scanline effects and terminal-inspired typography.
- **Project Matrix:** Overview of active, released, and upcoming technical projects.
- **Technical Blog:** Integrated markdown-based blogging system.

## Tech Stack

- **Framework:** [Nuxt 4](https://nuxt.com)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com)
- **Content:** [Nuxt Content v3](https://content.nuxt.com)
- **Deployment:** GitHub Pages

## Projects Highlighted

- **Zena Linux:** Bootc-based, immutable operating system.
- **FuzPad TUI:** Minimalist Bash-based note management system.
- **Zerith OS:** Reproducible OS constructed with MKOSI.
- **Dorrafy:** Legacy Document Retrieval Platform.
